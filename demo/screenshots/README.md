# SafeSearch AI — Application Screenshots

This folder contains screenshots demonstrating the SafeSearch AI web application and its main features.

SafeSearch AI is an AI-assisted missing-person investigation and search-prioritization prototype. It allows investigators to add missing-person cases, analyze investigation evidence, calculate search-priority scores, and visualize investigation information on an interactive map.

## Screenshot Naming Convention

Name screenshots sequentially so they appear in the correct demonstration order:

  01-landing-page.png
      ← SafeSearch AI dashboard / main application interface

  02-case-selection.png
      ← Missing-person case selection and case information

  03-case-analysis.png
      ← Analysis results including evidence, crime risk,
         search priority and priority level

  04-investigation-map.png
      ← Interactive investigation map showing relevant locations,
         investigation leads and search-priority areas

  05-add-missing-person.png
      ← Adding a new missing-person case through the web interface

  06-new-case-analysis.png
      ← Newly added case processed through the complete investigation pipeline

## Screenshot Requirements

- Minimum: 3 screenshots
- Recommended: 5–6 screenshots
- Format: PNG or JPG
- Screenshots must show the application running in a browser.
- Use real or realistic synthetic/demo data.
- Do not use empty states or placeholder screens.
- Keep the browser window size consistent across screenshots.
- Make sure important information is clearly visible.
- Use screenshots that demonstrate the actual functionality of SafeSearch AI.
- If synthetic data is used, clearly indicate that it is synthetic/demo data.
